# ⚛️ QuantumElement 3D / عنصر كوانتوم

> **A Multi-Scale Interactive Subatomic 3D Universe & Quantum Cinema for all 118 Elements of the Periodic Table.**

Built with **Next.js 14 (App Router)**, **React 18**, **Three.js**, **@react-three/fiber / @react-three/drei**, **GSAP**, **Zustand**, and **Tailwind CSS**.

---

## 🌟 Overview

**QuantumElement 3D** enables students, educators, and researchers to explore all 118 elements across **five powers of ten**—from the macroscopic Periodic Table down to the Planck scale vibrating strings of String Theory:

1. **Scale 1: Periodic Table ($10^0\text{ m}$)** — 18-column IUPAC grid with color-coded categories, raycasting, dynamic canvas textures, and orbital card illumination.
2. **Scale 2: Atomic Shells ($10^{-10}\text{ m}$)** — Elliptical Bohr electron orbits ($K, L, M, N, O, P, Q$), glowing electron cores, orbital history trails, photon excitation, and $880\text{ Hz}$ quantum leap sine decay.
3. **Scale 3: Packed Nucleus ($10^{-14}\text{ m}$)** — Dynamic Fibonacci sphere packing for all nucleons ($A = Z + N$), radial gradient crimson protons ($+$) and sky-blue neutrons ($0$), Yukawa $\pi$-meson exchange filaments, zero-point quantum jitter, and 3D nucleon tooltip.
4. **Scale 4: Subatomic Quarks ($10^{-18}\text{ m}$)** — Valence $uud$ (proton) and $udd$ (neutron) quarks with fractional charges ($+2/3e, -1/3e$), $SU(3)$ color confinement flux tubes, traveling gluon energy beads, virtual sea quarks popping from vacuum, and live $W^-$ boson Weak Force Beta decay simulation.
5. **Scale 5: Planck Scale Strings ($10^{-35}\text{ m}$)** — 1D vibrating Planck string standing wave solver with 4 harmonic eigenmodes (Electron, Quark, Photon, and Graviton closed loop leaking into extra-dimensional bulk), plus 6D Calabi-Yau manifold projection.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ (tested on Node v20/v23)
- npm or yarn or pnpm

### Installation
```bash
git clone https://github.com/marait123/quantum-element-3d.git
cd quantum-element-3d
npm install
```

### Running Locally
```bash
# Start development server
npm run dev

# Or build for production
npm run build
npm run start -p 4000
```
Open [http://localhost:4000](http://localhost:4000) (or default port) in your browser.

### Running End-to-End Tests
```bash
node scratch/e2e_test.js
node scratch/test_video_ux.js
```
